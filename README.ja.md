# vivliostyle_doc

このリポジトリには、Vivliostyle のサンプル文書とプレゼンテーション資料を収めています。

## Vivliostyle のサンプル

これらのサンプルは [Vivliostyle のサンプル](https://vivliostyle.org/ja/samples/)のページで見られます。

## Vivliostyle で作った本・報告書・プレゼンテーション

[en](https://github.com/vivliostyle/vivliostyle_doc/tree/gh-pages/en)（英語）と [ja](https://github.com/vivliostyle/vivliostyle_doc/tree/gh-pages/ja)（日本語）の各サブフォルダにある README を参照してください。
